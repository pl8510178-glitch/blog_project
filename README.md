# Blog CRUD Application

## 📌 Project Description

This project is a Blog CRUD Application developed using PHP and MySQL. It allows users to register, log in, create blog posts, view posts, edit existing posts, and delete posts. The project demonstrates the implementation of CRUD operations and user authentication in a web application.

## 🚀 Features

* User Registration
* User Login and Logout
* Create Blog Posts
* View Blog Posts
* Edit Blog Posts
* Delete Blog Posts
* Session Management
* Database Connectivity using MySQL

## 🛠️ Technologies Used

## ⚙️ How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Place the project folder inside the htdocs directory.
4. Create the required database in phpMyAdmin.
5. Run the project using:

http://localhost/blog_project
